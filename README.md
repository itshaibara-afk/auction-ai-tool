# オークションシートAI診断ツール

車のオークションシート（USS・TAA・JUなど）の写真をアップロードすると、AIが評価点・車両図の傷/凹み記号・特記事項を解説し、「買い / 条件付き買い / 見送り推奨」を根拠つきで判定するローカルWebアプリです。

使うほど、フィードバックと購入後の結果報告からAI自身の判定ルールが育っていく仕組みを備えています。

## できること

- オークションシート画像のアップロード → AIによる徹底解説（評価点・内装評価・車両図の記号・特記事項・懸念点・入札前チェックリスト）
- 「買い / 条件付き買い / 見送り推奨」の3段階判定と理由
- **AIを育てる仕組み（3種類）**
  1. **フィードバック学習**：各診断結果に「妥当だった/一部違った/大きく違った」＋コメントを入力すると、指摘内容が即座に学習ルールとして蓄積され、次回以降の診断プロンプトに反映される
  2. **購入後の結果トラッキング**：実際に購入した場合の状態・修理費用・シートになかった問題点を記録し、統計として蓄積
  3. **AIによる自己振り返り（「AIを育てる」画面）**：蓄積されたフィードバックと購入後結果をAI自身に読ませ、新しいルール案を提案させる。内容を確認して承認すると学習ルールに反映される
- 「設定」画面から評価基準ナレッジ（ベースルール）を直接編集可能。会場独自のルールや自分の判断基準を書き足せる
- 統計ダッシュボードで診断件数・自己申告正解率・判定内訳を確認可能

## セットアップ

### 1. 必要なもの

- Python 3.9以上
- AIのAPIキー（どちらか一方でOK。「設定」画面で切り替えられます）
  - **無料で使いたい場合：Gemini APIキー**（[Google AI Studio](https://aistudio.google.com/apikey) で無料発行。無料枠は1日あたり約1,500リクエストで、通常の社内利用なら十分。※無料枠では送信データがGoogleのモデル改善に使われる場合があります）
  - **精度重視の場合：Anthropic APIキー**（[console.anthropic.com](https://console.anthropic.com/settings/keys) で発行。従量課金制で、画像解析1回あたり数円〜数十円程度の見込み）

### 2. インストール

```bash
cd auction-ai-tool
pip install -r requirements.txt
```

### 3. 起動

```bash
python run.py
```

ブラウザで `http://127.0.0.1:5050` を開いてください。

### 4. APIキーの登録

初回起動後、画面右上の「設定」からAnthropic APIキーを貼り付けて保存してください。
キーはこのフォルダ内の `.env` ファイルにのみ保存され、外部には送信されません。

## 使い方の流れ

1. トップページでオークションシートの画像をアップロード → 「AIに診断させる」
2. 結果画面で解説・判定を確認
3. 判定が実際と違っていたら「フィードバック」欄にコメントを入力して送信 → 次回以降の診断に自動反映
4. 実際に購入したら「購入後の結果を記録する」欄に結果を入力 → 統計と将来のルール改善に活用
5. ある程度データが溜まったら「AIを育てる」画面で「AIに振り返らせて提案を作成する」を実行 → 提案内容を確認して承認すると学習ルールに追加される

## データの保存場所

- `app/data/app.db` … 診断履歴・フィードバック・購入後結果（SQLite）
- `app/data/uploads/` … アップロードされたシート画像
- `app/knowledge/auction_sheet_knowledge.md` … ベースとなる評価基準ナレッジ（設定画面から編集可）
- `app/knowledge/learned_rules.md` … フィードバック/AIの振り返りから蓄積された学習ルール
- `.env` … Anthropic APIキー

すべてローカルのファイルとして保存されるため、バックアップしたい場合は `app/data` と `app/knowledge` と `.env` をコピーしてください。

## 社内で共有する（複数人で使う）

1台のPC（またはサーバー）でこのアプリを動かし、社内の他のメンバーはブラウザからアクセスする形で共有できます。メンバー側にはPythonもClaudeアカウントも不要です。

### 手順

1. アプリを動かすPCを1台決める（普段つけっぱなしにできるPCが理想）
2. そのPCで通常どおりセットアップし、「設定」画面でAPIキーを登録する
3. 同じ「設定」画面の「社内共有（合言葉ログイン）」で共有合言葉を設定する
4. 共有モードで起動する：

```bash
python run.py --share
```

5. 起動時に表示されるURL（`http://<このPCのIPアドレス>:5050`）を社内メンバーに伝える

メンバーは初回アクセス時に「名前＋合言葉」を入力します。以降、誰が診断・フィードバックしたかが記録され、全員のフィードバックが同じ学習ルールに蓄積されるため、チーム全体でAIを育てられます。

### 完全無料でインターネット上のサイトとして公開する（Render + Gemini）

PCを起動しっぱなしにしなくても、無料のクラウドサービスに設置すれば、社内の誰でも・どこからでもURLひとつでアクセスできる「サイト」になります。

**無料構成：** Render（無料プラン）＋ Gemini API（無料枠）＝ 月額0円

手順：

1. [Google AI Studio](https://aistudio.google.com/apikey) でGemini APIキーを無料発行する
2. [GitHub](https://github.com) にこのフォルダ一式をアップロードする（リポジトリ作成 → ファイルをドラッグ&ドロップでも可）
3. [Render](https://render.com) に無料登録し、「New +」→「Web Service」→ 手順2のGitHubリポジトリを選択
4. プラン「Free」を選び、環境変数に以下を設定してデプロイ：
   - `AI_PROVIDER` = `gemini`
   - `GEMINI_API_KEY` = 手順1のキー
   - `ACCESS_PASSWORD` = 社内共有の合言葉
5. 発行されたURL（`https://〜.onrender.com`）を社内メンバーに共有する

**Render無料プランの注意点：**

- 15分間アクセスがないとスリープし、次のアクセス時の起動に30秒〜1分ほどかかります（起動後は普通の速度）
- **無料プランはディスクが永続化されないため、再デプロイやサービスの再起動で診断履歴・学習ルールが消えます。** 蓄積データを確実に残したい場合は、Renderの有料ディスク（月数百円）を付けるか、PythonAnywhere（無料プランでもファイルが消えない）への設置、もしくは社内PCでの `--share` 運用をおすすめします
- 学習ルール等は「設定」画面からコピーしてバックアップできます

### 社内共有時の注意

- API利用料は、この1台に登録されたAPIキーにまとめて課金されます（1診断あたり数円〜数十円 × チームの利用回数）
- 同じオフィスのネットワーク（LAN/Wi-Fi）内からのみアクセスできます。社外からも使いたい場合はVPN、またはクラウドサーバー（VPS等）への設置が必要です
- インターネットに直接公開する場合は、HTTPS化（リバースプロキシ）などの追加のセキュリティ対策を必ず行ってください。合言葉ログインは社内LAN想定の簡易的なものです

## 注意事項

- このツールの判定はオークションシートの記載内容に基づくAIの推定であり、実車確認や専門家への相談に代わるものではありません。最終判断は必ずご自身の目・信頼できる業者の確認と合わせて行ってください。
- オークションシートの評価基準は会場・検査員によって多少異なります。特定の会場に特化させたい場合は「設定」画面でナレッジを編集してください。
- `app.secret_key` はローカル利用を前提にした固定値です。他人がアクセスできる環境で公開する場合は必ず変更し、HTTPS化・認証の追加を行ってください。
