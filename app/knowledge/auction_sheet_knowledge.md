# 日本の中古車オークションシート 解読ナレッジベース

このファイルはAI解析エンジンがオークションシートを解説・判定する際に読み込む「知識」です。
内容はUSS・TAA・JU（自動車公正取引協議会/JAAI統一基準）など主要オークション会場でおおむね共通する評価体系をまとめたものです。
※出品店舗や会場によって多少の差異があるため、シート右上の「会場名」「出品店名」も必ず読み取り、会場固有の注記があればそちらを優先すること。

---

## 0. 前提条件：落札車両はすべてオーストラリア輸出向け

**このユーザーが入札する車両は、例外なくすべてオーストラリアへの輸出用である。** 判定ロジックは常にこの前提を踏まえること（国内再販前提の一般的な基準とは重視ポイントが変わる）。

- **右ハンドル(RHD)は問題にならない**：オーストラリアもRHD国のため左右ハンドル変換のコストは発生しない。この点は減点材料にしなくてよい。
- **年式・車種による輸入可否を優先確認**：オーストラリアの中古車個人・業者輸入は主に(1)製造から25年以上経過した車両向けの年式条件付き免除、(2)SEVS（Specialist and Enthusiast Vehicle Scheme）適合車種リストによる輸入、(3)RAWS（Registered Automotive Workshop Scheme）登録事業者の輸入枠、のいずれかを通す必要がある。25年に満たない年式かつSEVS対象外の一般的な乗用車・ミニバン（アルファード、エスティマ、ハイエース等）は、業者がRAWS枠を使って輸入するのが一般的なルート。個別の車両を評価する際、この枠が使える車種かどうかは輸出事業者側の把握事項であるため、AIは断定せず「輸入可否・輸入方式の再確認」を注意喚起にとどめる。
- **修復歴（骨格・フレーム系）はオーストラリア独自の観点でも要注意**：現地では輸入車両に対しADR（Australian Design Rules、特に側面衝突基準ADR85等）への適合確認やコンプライアンス（保安基準適合）検査が行われる。サイドメンバー・コアサポート・クロスメンバーなど骨格部位の歪み・修正歴がある車両は、この検査で追加の修正コスト・時間がかかる、または現地の検査官によっては通らないリスクがあるため、国内再販目線よりも一段重く評価してよい。ただし実際の可否は最終的に現地のRAWS登録工場・通関業者の判断次第であり、AIは「輸入・コンプライアンス時に指摘されるリスクがある」という注意喚起にとどめ、断定的な合否判断はしないこと。
- **冠水歴（水没）は特に重要**：オーストラリア向け輸出では水没歴のある車両は現地で問題になりやすいとされる。シートや特記事項に「冠水」の記載がないか必ず確認し、あれば強く注意喚起する。
- **走行距離表記（km）はそのまま現地でも通用**：オーストラリアもkm表記のためメーター単位の変換は不要。
- **会場ごとの評価基準の違い（TAA/USS等）**：ユーザーは「TAAオークションなら買うが、USSオークションなら同じR評価でも買わない」という判断基準を持っている。会場によって検査員のR評価の付け方・厳格さに差があるという考え方に基づくと考えられるが、詳細な使い分けのルールは追加のヒアリング待ち（ユーザーからの共有資料を参照）。現時点では、**シート右上の会場名を必ず読み取り、会場名を解析結果に明記したうえで、会場による評価基準の厳格さの違いがあり得ることを一言添える**にとどめる。

## 1. 総合評価点（グレード）

オークションシート左上または中央上部に大きく記載される、車両全体のコンディションを示す点数。

| 評価点 | 意味 |
|---|---|
| 6 | 新車同然・未使用車 |
| 5 | 走行距離極少・内外装ほぼ新車状態 |
| 4.5 | 非常に良好。目立つ傷なし |
| 4 | 良好。年式なりの小傷程度 |
| 3.5 | 標準的な使用感。多少の傷・修復小あり |
| 3 | 使用感あり。傷・凹みが複数、または軽度の修復歴 |
| 2 | 修復歴あり、またはコンディション低い（傷・凹み多数、内外装消耗大） |
| 1 | 修復歴あり・状態が悪い個体 |
| R / RA | 修復歴あり（骨格部位の修正・交換歴）。数字評価より前にR表記が付くこともある |
| S | 新車から短期間の登録済み未使用車（Show車等）に付くことがある |
| A/B/C（会場により） | 業者専用会場などグレード表記が独自の場合あり |

**買い判定への影響（目安）：**
- 4.5以上：外装はほぼ気にしなくてよい。年式・価格相応であれば積極的に検討可
- 3.5〜4：小傷は許容範囲。シートの傷記号の「数」と「場所（運転席側・目立つ面）」を要チェック
- 3以下：傷・凹みの箇所と深刻度を必ず精査。走行距離や価格次第では「割安な実用車」にもなり得るが、要注意
- R/RA（修復歴あり）：フレーム・骨格部位（クロスメンバー、サイドメンバー、ピラー、ルーフ、フロア等）に交換・修正歴。事故の規模次第で資産価値・安全性に大きく影響するため、**修復箇所の具体的な部位**をシートから読み取り、必ず注意喚起する

## 2. 内装評価点

車内の状態を示す評価。外装評価とは別枠で記載されることが多い。

| 内装評価 | 意味 |
|---|---|
| A | 内装の状態が良い（シミ・汚れ・タバコ臭等なし） |
| B | 普通。多少の使用感あり |
| C | 悪い。シミ・破れ・強い臭い・改造跡など |
| D | 非常に悪い。特記が必要なレベル |

タバコ臭・ペット臭は「臭usage」欄や特記事項（金額表記の下の自由記述欄）に「ヤニ臭」「ペット臭」等の文字で記載されることが多いので、そこも読み取る。

## 3. 車両図（ボディダメージダイヤグラム）の記号

オークションシート中央にある車の展開図（上から見た図＋四方向）に記号が書き込まれる。これが最も重要な情報。

| 記号 | 意味 |
|---|---|
| A1 | 小さな傷（爪が引っかからない程度） |
| A2 | 大きな傷（複数・目立つ傷） |
| B1 | 小さな凹み |
| B2 | 大きな凹み |
| C | 傷と凹みが同時にある状態 |
| S1 | 小さなサビ |
| S2 | 大きなサビ |
| W1 | 小さな凹み（波状の凹み、正確には「浅い面の凹凸」） |
| W2 | 大きな凹み・波状変形 |
| U1 | 修理歴あり（小規模な修理・補修跡） |
| U2 | 修理歴あり（大規模な修理跡・塗装含む） |
| U3 | 修理歴あり（U2よりさらに大規模・深刻な補修跡。会場により使われる表記で、特にルーフ等で見られた場合はユーザーの仕入れ基準上、原則入札しない対象） |
| X1 | 交換されたパネル（小さな部品） |
| X2 | 交換されたパネル（大きな部品・要注意） |
| P | 塗装補修・タッチペイント跡 |
| E | ひどい凹み（大変形） |
| Y | ヤケ・変色 |
| N | ナビ・機器不良（車両図ではなく装備欄に出ることもある） |

**位置の読み方：** 図はフロント/リア/左右サイド/ルーフ/ボンネット/トランクの各パネルに対応しており、記号が書かれているパネル名（例：右フロントフェンダー、左リアドア等）を必ず日本語で明示して説明する。「どこに何があるか」が買い判断で最も重要。

## 5. 走行距離とオドメーター表記

- km表記の横に「A」「M」などの記号がつく場合、メーター交換歴やロールバック（改ざん）の可能性を示すことがある
- 走行距離が年式に対して極端に少ない（年1000km未満など）場合は「実走不明」の疑いがないかシート特記事項を確認するよう案内する

## 6. 「買いか否か」の総合判定ロジック（初期ルール・v1）

AIはこの優先順位で判定を組み立てる。**ユーザー独自の仕入れ基準（下記7.）が最優先**。次にユーザーからのフィードバックや実績データが蓄積された場合は`learned_rules.md`の内容を、それ以外はこのデフォルトルールを適用する。

0. **ユーザー独自の仕入れ基準（下記7.参照）との照合を最初に行う**：評価点・走行距離・色・ブランド別基準・ルーフのU3以上・元レンタカー・半事故車のいずれかに抵触する場合は、それだけで「見送り推奨」または少なくとも「条件付き買い」に格下げし、該当する基準を具体的に理由として明記する
1. **修復歴（R/RA）の有無と部位**：フレーム主要部位（サイドメンバー、クロスメンバー、ピラー、ルーフ等）の修復は原則「要注意・減点大」。外板のみの軽微な修理（バンパー等）は影響小。**輸出先はすべてオーストラリア（上記0.参照）であるため、骨格系の修復歴は現地コンプライアンス（ADR適合検査）で追加コスト・リスクになり得る点を明記すること**
1.5. **冠水歴の有無**：特記事項に冠水・水没を示す記載がないか必ず確認し、あれば最優先で注意喚起する（オーストラリア向け輸出では特に問題視されやすい）
2. **総合評価点**：3.5以上は基本的にプラス材料。3以下はダメージ記号の内容を精査
3. **車両図の記号密度と場所**：目立つ面（フロント、運転席側ドア）に大きな傷・凹み（A2/B2/W2/X2）が集中している場合は減点
4. **内装評価**：C/D評価、または臭い・シミの特記がある場合は減点（実用面・再販価値に影響）
5. **走行距離・メーター信頼性**：不明瞭な記載がある場合は要注意フラグを立てる
6. **価格とのバランス**：上記のマイナス要素があっても、相場や出品予定価格（分かる場合）に対して十分に安ければ「条件付きで買い」もあり得る。金額情報がなければ「相場を確認のうえ判断を」と案内する

**出力する結論は必ず以下の3段階＋理由で提示する：**
- 「買い」：グレード・修復歴・内外装ともに大きな懸念なし
- 「条件付き買い」：具体的な懸念点はあるが、価格や用途次第では許容範囲
- 「見送り推奨」：修復歴の部位・程度、または複数の重大な懸念があり、リスクが高い

## 7. ユーザー独自の仕入れ基準（最優先ルール・スプレッドシート由来）

ユーザーが実際の仕入れで使っている基準。他のどのルールよりも優先して判定に適用すること。

**購入基準**
- 総合評価点は3.5〜5を目安とし、3.5以下（3.5を含む）は原則買わない。ただしRなど骨格修復歴車は数値評価と別枠のため、7.の他基準および上記1.の修復歴ロジックで個別判断する
- 走行距離は50,000km以下が目安。50,000kmを超える場合は減点材料として明記する
- 色は白・黒・パール・シルバーを優先。それ以外の色は必須ではないが、色の記載があれば一言触れる
- 内装・外装の個別評価はA〜Cが対象範囲。D評価は原則対象外
- **ルーフのダメージ記号がU3以上の場合は原則入札しない**
- **元レンタカー（特記事項に記載がある場合）は評価が低いとみなし、注意喚起する**
- **「半事故車」（Rほど明確ではないが事故を思わせる複数のダメージ・違和感のある修復跡がある車両）に注意し、疑わしい場合はその旨を明記する**
- **トヨタ・ホンダ車は、傷の程度がA1/A2（小さな傷）かつ板金（凹み修理・パネル交換）なしであることが基準**。B/W/X系の記号が付いている場合は基準外である旨を明記する

**コスト参考情報（総額試算のコメントに使ってよい）**
- オークション落札手数料：約1万円
- 業販サイト掲載費用：約1.5万円
- 陸送費の目安（会場所在地基準）：北海道 約4万円／関東 約1万円／東北 約2万円／中部 約2万円／近畿 約3万円／広島 約5万円／九州 約4万円（地域は変動するため目安として言及する）
- 部品交換費用の目安：バンパー 約1.5万円／ルーフ 約5万円／その他ドア 約2万円／社外ステレオ用の穴の補修 約3〜4万円
- 上記はあくまで参考値。実際の総コストは車両価格＋これらの費用＋（該当すれば）船賃・現地コンプライアンス費用等で変動するため、断定的な金額は避け「参考目安」として案内する

## 8. 免責事項として必ず添える文言

AIによる解析はシートの記載内容に基づく推定であり、実車確認（現車確認）や信頼できる業者への相談に代わるものではないこと、オークションシートは出品者・検査員の主観が入るため会場や検査員によって基準の厳しさが異なることを、回答の最後に必ず一言添える。
